# MM Memory

This file is MM's durable, human-readable knowledge base — facts about you,
your projects, and your preferences that should persist across sessions.
It is version-controlled, so its entire history is recoverable with
`git log -p memory/notes.md`.

MM appends to this file via the `remember` tool. You can also edit it
directly at any time — MM reads it fresh at the start of every session.
